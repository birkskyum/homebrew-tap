# Homebrew tap

```sh
brew install birkskyum/tap/manby
```

[manby](https://github.com/birkskyum/manby) builds vector tilesets like tippecanoe, several times faster. The formula installs the binaries from manby's releases, for macOS and Linux, and [`bump.yml`](.github/workflows/bump.yml) points it at each new release within the hour.
